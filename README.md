# GoIT HTML/CSS Team Project - YachtJet Responsive Adaptation (HTML/CSS)
This was originally a team homework assignment for the GoIT course (Modules 5-6), designed to be split across a team, but was completed solo by choice — all six sections were implemented by one person. Topic: mobile-first responsive design, media query breakpoints, a mobile navigation menu, and responsive images (`srcset`, `image-set()`, `picture`/`source`).
**What was done:**
- Continued the YachtJet project from the pre-configured Vite starter template (mobile-first CSS scaffolding with breakpoints already in place, `.container`, `.sr-only` and `.hidden` helper classes, previous desktop styles kept as reference in `-old.css` files) and adapted all six sections — Header, Hero, Catalog, About, Reviews and Footer — from mobile through tablet to desktop, working exclusively within each section's own partial and CSS file
- **Header & mobile menu:** Hid the desktop navigation and social links on mobile, built a burger button with an SVG icon and a full-screen mobile menu (close button, navigation, social links) toggled by an `.is-open` class, and revealed the desktop navigation and social links from the 768px breakpoint while hiding the mobile-only elements, keeping the header positioned over the Hero at every width
- **Hero:** Adapted spacing, typography and content width mobile-first, added a 2x background image variant via `image-set()`, and adjusted the section and content sizing at the 768px and 1280px breakpoints while keeping text and the button readable and within the container
- **Catalog:** Adapted the heading, cards and button mobile-first, controlled card visibility through media queries so one card shows on mobile, two on tablet and three on desktop, added `1x`/`2x` `srcset` image variants, and calculated card widths accounting for the gap between them
- **About:** Rebuilt the section composition for mobile, tablet and desktop, adapted the benefits list and image block, and used `<picture>`/`<source>` to serve the right mobile, tablet or desktop image, each with `1x`/`2x` `srcset` variants
- **Reviews:** Adapted the heading, description and review cards mobile-first, controlled card visibility through media queries (one card on mobile, two on tablet, three on desktop), added `1x`/`2x` `srcset` variants for user photos, and calculated equal card widths accounting for the gap
- **Footer:** Adapted the top block's element order for each breakpoint, configured the navigation and social links per screen width, adapted the main text's width and typography, aligned the copyright and Privacy Policy link, and preserved accessible hover/focus states with smooth transitions
- **Shared conventions:** Followed a mobile-first approach throughout, used only `.container`, `.sr-only` and `.hidden` without redefining them, adapted (rather than copy-pasted) the reference desktop styles from the `-old.css` files, applied the 768px and 1280px breakpoints consistently, avoided fixed widths in favor of `max-width`/percentages/flexible grids, verified no horizontal scroll at 320px, 375px, 768px, 1280px and in between, and left the shared `common.css`, `main.css`, `index.html`, Vite config and other contributors' files untouched

# Командний проєкт GoIT HTML/CSS — Адаптивна верстка YachtJet (HTML/CSS)
Спочатку це було командне практичне завдання з курсу GoIT (Модулі 5-6), розраховане на розподіл між учасниками команди, проте виконане самостійно, за власним рішенням — усі шість секцій реалізовано однією людиною. Тема: mobile-first адаптивна верстка, медіазапити з точками перелому, мобільне навігаційне меню та адаптивні зображення (`srcset`, `image-set()`, `picture`/`source`).
**Що зроблено:**
- Продовжено роботу над проєктом YachtJet на основі підготовленого стартового шаблону з Vite (mobile-first CSS-каркас із заданими точками перелому, допоміжні класи `.container`, `.sr-only` та `.hidden`, попередні desktop-стилі збережені як орієнтир у файлах `-old.css`), адаптовано всі шість секцій — Header, Hero, Catalog, About, Reviews та Footer — від мобільної версії через планшетну до desktop, працюючи виключно у власних partial- та CSS-файлах кожної секції
- **Header та мобільне меню:** На мобільному приховано desktop-навігацію та соціальні посилання, реалізовано кнопку burger зі SVG-іконкою та повноекранне мобільне меню (кнопка закриття, навігація, соціальні посилання), яке перемикається класом `.is-open`, від точки перелому 768px показано desktop-навігацію та соціальні посилання з прихованням мобільних елементів, Header залишається поверх Hero на всіх ширинах
- **Hero:** Адаптовано відступи, типографію та ширину контенту за підходом mobile-first, додано версію фонового зображення 2x через `image-set()`, розміри секції та контенту скориговано в точках перелому 768px і 1280px, текст і кнопка залишаються читабельними та в межах контейнера
- **Catalog:** Адаптовано заголовок, картки та кнопку за підходом mobile-first, видимість карток керується через медіазапити: одна картка на мобільному, дві на планшеті, три на desktop, додано варіанти зображень `1x`/`2x` через `srcset`, ширину карток розраховано з урахуванням gap між ними
- **About:** Перебудовано композицію секції для мобільного, планшетного й desktop-екрана, адаптовано список переваг і блок із зображенням, для вибору потрібного мобільного, планшетного чи desktop-зображення використано `<picture>`/`<source>`, кожен варіант містить `1x`/`2x` у `srcset`
- **Reviews:** Адаптовано заголовок, опис і картки відгуків за підходом mobile-first, видимість карток керується через медіазапити (одна картка на мобільному, дві на планшеті, три на desktop), додано варіанти `1x`/`2x` у `srcset` для фото користувачів, ширину карток розраховано однаковою з урахуванням проміжків
- **Footer:** Адаптовано порядок елементів верхнього блока для кожної точки перелому, налаштовано навігацію та соціальні посилання під різні ширини, адаптовано ширину й типографію основного тексту, вирівняно копірайт і посилання Privacy Policy, збережено доступні hover і focus стани з плавними переходами
- **Спільні підходи:** Верстка виконана за підходом mobile-first, використано лише готові `.container`, `.sr-only` та `.hidden` без їх перевизначення, стилі з файлів `-old.css` не перенесено механічно, а адаптовано під новий макет, послідовно застосовано точки перелому 768px і 1280px, фіксовану ширину замінено на `max-width`, відсотки або гнучку сітку там, де це можливо, перевірено відсутність горизонтального скролу на 320px, 375px, 768px, 1280px і проміжних ширинах, спільні файли `common.css`, `main.css`, `index.html`, конфігурацію Vite та файли інших учасників не змінено
