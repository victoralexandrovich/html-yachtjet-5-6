# GoIT HTML/CSS Team Project - YachtJet Desktop Styling (HTML/CSS)
This was originally a team homework assignment for the GoIT course (Modules 3-4), designed to be split across a team, but was completed solo by choice — all six sections were implemented by one person. Topic: Vite-based project structure, Flexbox layout, the CSS box model, `calc()`-based sizing, SVG icon sprites, and smooth interactive transitions.
**What was done:**
- Continued the YachtJet project from the Vite-powered starter template (pre-configured project structure, shared `.container` and `.sr-only` classes, base styles) and completed the desktop layout for all six sections: Header, Hero, Catalog, About, Reviews and Footer, working exclusively within each section's own `src/partials/*.html` and `src/css/*.css` files
- **Header:** Positioned the header over the Hero section as a light rounded panel with a border, laid out the logo, navigation and social links with Flexbox, connected SVG social icons via a sprite (`<svg><use>`) with icon color controlled through `color`, and added `:hover`/`:focus` states with 250ms `cubic-bezier(0.4, 0, 0.2, 1)` transitions on explicitly named properties
- **Hero:** Added a CSS background image sized and positioned to fill the section without repeating, centered the section with a max-width, built the section height from vertical padding, constrained and centered the heading, description and button, and gave the button smooth hover/focus transitions
- **Catalog:** Laid out three equal-width yacht cards in a row using `calc()` to account for the gap between cards, added card padding and rounded corners, aligned each card's name/type row and specification list with Flexbox, and centered a button below the cards with hover/focus transitions
- **About:** Visually hid the section heading with `.sr-only`, placed the activity list and image side by side with Flexbox (list filling the available space, image block fixed via `flex-shrink`), arranged the four list items into two columns, added a decorative line under each number using an `::after` pseudo-element, and clipped the image inside its rounded container
- **Reviews:** Added vertical section padding, centered the heading and description with a constrained width, laid out three equal-width review cards in a row using `calc()` and `gap`, styled each card with padding, background and rounded corners, and made the user photos circular
- **Footer:** Built the top row (logo, navigation, social links) with Flexbox, connected SVG social icons via the same sprite technique, centered the main footer text within a max-width, aligned the copyright and Privacy Policy link in a row, and added hover/focus states with the same 250ms cubic-bezier transitions
- **Shared conventions:** Used Flexbox only where elements needed to sit in a row or be aligned, avoided `transition: all` in favor of explicitly listed animated properties, sized blocks by content and padding rather than fixed heights, and left the shared `common.css`, `main.css`, `index.html`, Vite config and other contributors' files untouched

# Командний проєкт GoIT HTML/CSS — Desktop-стилізація YachtJet (HTML/CSS)
Спочатку це було командне практичне завдання з курсу GoIT (Модулі 3-4), розраховане на розподіл між учасниками команди, проте виконане самостійно, за власним рішенням — усі шість секцій реалізовано однією людиною. Тема: структура проєкту на Vite, компонування за допомогою Flexbox, блокова модель CSS, розрахунок розмірів через `calc()`, SVG-спрайти іконок та плавні інтерактивні переходи.
**Що зроблено:**
- Продовжено роботу над проєктом YachtJet на основі стартового шаблону з Vite (готова структура проєкту, спільні класи `.container` та `.sr-only`, базові стилі), реалізовано desktop-оформлення всіх шести секцій: Header, Hero, Catalog, About, Reviews та Footer, працюючи виключно у власних файлах `src/partials/*.html` та `src/css/*.css` кожної секції
- **Header:** Розташовано хедер поверх секції Hero у вигляді світлої панелі із заокругленням та рамкою, вибудувано логотип, навігацію та соціальні посилання за допомогою Flexbox, підключено SVG-іконки соцмереж через спрайт (`<svg><use>`) з керуванням кольором іконок через `color`, додано стани `:hover`/`:focus` із плавними переходами 250ms на `cubic-bezier(0.4, 0, 0.2, 1)`
- **Hero:** Додано фонове зображення через CSS з коректним позиціюванням, розміром і без повторення, секцію відцентровано з обмеженою максимальною шириною, висота секції сформована вертикальними padding, заголовок, опис і кнопку обмежено за шириною та відцентровано, кнопці додано плавні hover/focus-переходи
- **Catalog:** Три картки яхт однакової ширини розташовано в один ряд з розрахунком ширини через `calc()` з урахуванням gap, картки отримали внутрішні відступи та заокруглення, назву й тип яхти та список характеристик вирівняно через Flexbox, під картками відцентровано кнопку з hover/focus-переходами
- **About:** Заголовок секції візуально приховано через `.sr-only`, список активностей та зображення розташовано в один ряд через Flexbox (список займає доступний простір, блок зображення зафіксовано через `flex-shrink`), чотири пункти списку утворюють дві колонки, під номером кожного пункту додано декоративну лінію через псевдоелемент `::after`, зображення обрізано в межах заокругленого контейнера
- **Reviews:** Додано вертикальні паддінги секції, заголовок та опис відцентровано з обмеженою шириною, три картки відгуків однакової ширини розташовано в один ряд через `calc()` та gap, картки оформлено внутрішніми відступами, фоном і заокругленням, фото користувачів зроблено круглими
- **Footer:** Верхній рядок (логотип, навігація, соціальні посилання) побудовано через Flexbox, SVG-іконки соцмереж підключено тим самим способом через спрайт, основний текст футера відцентровано з обмеженою шириною, копірайт і посилання Privacy Policy розташовано в один ряд, додано hover/focus-стани з тими самими переходами 250ms cubic-bezier
- **Спільні підходи:** Flexbox застосовано лише там, де елементи розташовуються в ряд або потребують вирівнювання, замість `transition: all` явно перелічено властивості, що анімуються, висота блоків формується контентом і padding без фіксованих значень, спільні файли `common.css`, `main.css`, `index.html`, конфігурацію Vite та файли інших учасників не змінено
